# CthulhuWell

Jogo de terror em primeira pessoa no qual você precisa atravessar um túnel escuro antes que uma criatura alcance você.

## Como jogar

Abra `index.html` em um navegador e escolha **Descer ao poço**.

- **W**: avançar em direção à saída
- **Shift**: correr; o fôlego se recupera enquanto você caminha
- **↑ / ↓**: olhar para cima ou para baixo
- **Esc**: pausar

Chegue à saída antes que a criatura alcance você.
