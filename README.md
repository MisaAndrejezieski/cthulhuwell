# CthulhuWell

Jogo de terror em primeira pessoa: corra por um corredor comprido até a porta no fim, antes que uma criatura humanoide de membros compridos e olhos vermelhos alcance você.

## Como jogar

Abra `index.html` em um navegador e escolha **Correr até a porta**.

- **W**: avançar em direção à saída
- **Shift**: correr; o fôlego se recupera enquanto você caminha
- **↑ / ↓**: olhar para cima ou para baixo
- **Esc**: pausar

Chegue à porta no fim do corredor antes que a criatura alcance você.
